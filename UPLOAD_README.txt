STRATTEC Big Red Book - production staging package

1. Upload STRATTEC_Big_Red_Book_Resource_2026-09-18.json to the repository root.
2. Upload the contents of images/strattec-big-red/ to:
      images/strattec-big-red/
   There are 942 JPG files. GitHub's web uploader may require batches.
3. Verify several raw image URLs, including p0001.jpg, p0301.jpg, p0742.jpg,
   p0901.jpg, and p0941.jpg.
4. Only AFTER the JSON and images are present, merge manifest_entry.json into
   manifest.json. This prevents users from installing a resource whose page
   images have not been uploaded yet.
5. In the app: Resources -> Resource Manager -> Check for Updates -> install
   STRATTEC Big Red Book.

The resource uses the app's generic top-level records format and generic image_url
field already supported by Pass 106.

STRATTEC / Briggs Historical Resource — v1

Sources:
- 1953–1961 Briggs & Stratton Automotive Lock and Key Catalog (70 PDF pages)
- 1987 Briggs & Stratton Automotive Lock & Key Catalog (24 PDF pages)

94 page-level searchable records are included, each linked to its original catalog page image.
Year and make metadata were assigned from visible catalog headings/index structure. Dense table values remain on the original page image rather than being guessed.

Upload the JSON to the repository root and the images folder to images/strattec-briggs-historical/. Then add manifest_entry.json to manifest.json.
